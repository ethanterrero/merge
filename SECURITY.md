# Security policy

Merge handles commuters' routes, schedules and identities, so we take security and privacy reports seriously.

## Reporting a vulnerability

Please don't open a public issue, pull request or discussion for a security problem.

Report it privately through GitHub's private vulnerability reporting: go to the repository's **Security** tab and choose **Report a vulnerability** (https://github.com/ethanterrero/merge/security/advisories/new). Only the maintainers can see the report.

Include what you can:

- what the problem is and what an attacker could do with it,
- steps or a proof of concept to reproduce it,
- the affected commit, screen, migration or API call.

Please don't access, change or keep other people's data while testing, and don't test against members' accounts. Use your own accounts or a local setup (see the README).

## What to expect

Merge is a small, early-stage open-source project. We'll acknowledge your report as soon as we can, keep you updated in the advisory while we fix it, and credit you there if you'd like.

## Scope

Especially welcome: anything that exposes a member's exact origin, destination or pickup point, reveals identity details before a ride is confirmed, bypasses blocks or row-level security, or leaks credentials or keys.
