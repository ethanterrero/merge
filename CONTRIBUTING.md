# Contributing to Merge

Thanks for helping improve commuter coordination.

1. Open an issue describing a bug or scoped feature before large changes.
2. Fork the repository and create a focused branch.
3. Run `npm install` and `npm run typecheck` before opening a pull request.
4. Explain what changed, how it was tested, and any privacy/safety implications.
5. Never commit credentials, production user data, exact home/work coordinates, or real identity records.

All contributions are reviewed. Security issues should not be disclosed in public issues; contact the maintainers privately.
